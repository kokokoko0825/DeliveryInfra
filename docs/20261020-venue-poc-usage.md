# 会場音声 PoC の利用と RTT 記録

## 変更

- 全ロール（管理者、カメラ、音声、登壇者、視聴者）に PoC のマイク・スピーカー画面を表示し、シグナリング API もログイン済みユーザーから利用可能にした。
- スピーカー端末で受信した RTT を、時刻・セッション開始/終了時刻・ブラウザ情報とともに、その端末のブラウザ内へ自動保存する。
- スピーカー画面の「RTT CSV」から記録を出力できる。保存は端末/ブラウザごとで、サーバーには送信しない。複数端末のデータは各端末から CSV を出力してまとめる。
- ブラウザ内には直近20セッション、各セッション最大3,600サンプル（約1時間分）を保持する。

## 使い方

1. PoC 用アカウントでログインし、`/venue/mic` または `/venue/speaker` を開く。
2. 通信ペアを接続する。RTT は約1秒ごとに自動保存される。
3. スピーカー画面の「RTT CSV」を押して測定結果を保存する。

## RTT の意味

RTT は DataChannel の ping/pong 往復時間で、片道の音声遅延を表すものではない。CSV は端末ごとに出力し、測定時刻とブラウザ情報を照合して比較する。
