# 映像途絶判定の見直し

## 変更内容

スイッチャーの映像状態監視は、これまで `getVideoPlaybackQuality().totalVideoFrames` の増加だけを見ていました。ブラウザによってこの値が更新されない場合、画面には映像が表示されていても「映像途絶」と誤判定することがあります。

監視時にフレーム数に加えて `<video>` の `currentTime` も確認し、どちらかが進んでいれば最終フレーム時刻を更新するようにしました。例えばフレーム数が変わらなくても再生時刻が進めば、映像を受信中として扱います。停止した場合は従来どおり2秒後に途絶と判定します。
