# カメラ映像の縦横比に応じた表示

## 変更内容

スイッチャーの配信キャンバスは従来の 1280×720 に固定したまま、カメラ映像の向きに応じて表示方法を調整する。縦向き映像は高さに合わせて全体を表示し、左右の余白を黒帯にする。横向き映像は従来どおり横幅に合わせて表示する。配信キャンバスに加え、スイッチャー画面下部の各カメラプレビューにも同じ表示方法を適用する。

## 実装

`apps/web/src/features/switcher/media/compositor.ts` でカメラ映像の幅と高さを比較し、縦向きの場合だけ `contain` を使う。`apps/web/src/features/switcher/components/MultiView.tsx` でも動画メタデータとサイズ変更イベントから向きを判定し、縦向き動画には `object-contain`、横向き動画には `object-cover` を使う。横向き映像、スライド、待機画面の描画方法は変えない。
