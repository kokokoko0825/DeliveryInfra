# Review-4 トリアージ（coordinator 判定）

判定: R4-01〜07 と、Review-3 に後から追記された R3-13・R3-14 の計9件はすべて妥当。R3-01〜12 は修正済みと確認された。

| ID | 修正方針 |
| --- | --- |
| R3-14 / R4-01 | 共通ルール: 状態を DB に確定した後の Chat イベント送信（SendEvent）は、短いバックオフで最大3回まで内部再試行する。それでも失敗したら警告ログを出し、操作自体は成功応答を返す。監査ログは SendEvent より前に出す。R2-03 の「ended 済みでも broadcast-ended を再送する」冪等な挙動は維持する。Web 側では、配信開始の応答が成功なら番組の送信を止めない。 |
| R3-13 | 仮パスワードの期限切れを専用メッセージで表示する。管理者が招待を再送できるようにする（AdminCreateUser の MessageAction=RESEND、A-05 に「招待を再送」）。 |
| R4-02 | コメント停止・解除時に該当ユーザーへ通知する（Chat カスタムイベント `comment-suspension-changed` を shared に追加。または DisconnectUser 後の再接続で再取得）。本人の画面は再読み込みなしで反映する。 |
| R4-03 | 審査 Lambda の DENY 理由ごとに、画面の表示を出し分ける。 |
| R4-04 | 初回パスワード設定のセッション切れを専用メッセージで表示し、ログイン画面からやり直す導線を出す。 |
| R4-05 | Safari ネイティブ HLS の復旧回数に上限を設け、復旧対象のエラーだけを扱う。 |
| R4-06 | Dialog・Sheet・Sidebar の読み上げ文言を日本語にし、閉じるボタンのタップ領域を 44px にする。 |
| R4-07 | API Lambda ロールから未使用の権限を削除する。 |
