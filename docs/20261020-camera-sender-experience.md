# カメラ送信画面の撮影 UI

## 変更内容

カメラ送信中はページ全体を覆うプレビュー表示に切り替える。撮影開始時に対応ブラウザーでは全画面表示を要求してタブやアドレスバーを隠す。端末名、前面・背面選択、説明文などは隠し、対応カメラではズームイン・アウト、送信停止を操作できるようにする。

## 実装

`apps/web/src/features/sender/CameraSendPage.tsx` でカメラトラックの `getCapabilities()` からズーム範囲を取得し、`applyConstraints()` でズームを変更する。ズーム非対応の端末・ブラウザーではズーム操作を表示しない。撮影開始時に Fullscreen API を呼び出し、送信停止・接続エラー時に全画面を解除する。送信が停止すると通常の設定画面に戻る。
